# Changelog

## 0.1.0 — unreleased technical candidate (2026-10-28)

### Added

- Position-aware LaTeX scanner for multi-file projects; exact file/line/column spans,
  CRLF/LF and Unicode code-point columns.
- V0 rules: undefined citation, undefined reference, duplicate label, malformed or incomplete
  bibliography entry, include escaping the workspace.
- Conservative V2 notation candidate with an explicit heuristic scope.
- Hard quote gate: no finding enters the ledger without a byte-exact quote and matching hash.
- Safe ZIP import with zip-slip, symlink, absolute path, bomb and depth protection.
- Deterministic author style profile with sample-size abstention; drift cards with confidence.
- Model-free cognitive skeleton, label topology, symbol index and familiarity navigator.
- Three-pane React/Vite workbench with source jumping, accept/dismiss and exports.
- Native Windows and macOS launchers; offline wheelhouse builder; CLI (`serve`, `audit`, `demo`).
- Synthetic corpus and adversarial fixtures (ADV-01 … ADV-06).

### Not included

- No cloud model calls, no metadata network lookup, no PDF preview, no compilation.
- No macOS acceptance run and no Muse verdict; G1–G5 remain open.
